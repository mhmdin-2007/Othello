# Othello (Reversi)

A simple implementation of the classic **Othello (Reversi)** game written in **C++**.

![C++](https://img.shields.io/badge/C%2B%2B-17-blue)
![CMake](https://img.shields.io/badge/CMake-3.10+-green)
![License](https://img.shields.io/badge/License-MIT-yellow)

## 📖 About

This project is a console-based implementation of the classic Othello (Reversi) board game. It supports both **Player vs Player** and **Player vs Bot** modes, along with multiple bot difficulty levels and game save/load functionality.

##  Features

-  Classic Othello gameplay
-  Player vs Player mode
-  Player vs Bot mode (Easy, Medium, Hard)
-  Save and load games
-  Valid move validation
-  Automatic winner detection

## 🚀 Getting Started

### Requirements

- C++17 compatible compiler
- CMake 3.10 or later

### Build

```bash
git clone https://github.com/mhmdin-2007/Othello.git
cd Othello

mkdir build
cd build

cmake ..
cmake --build .
```

### Run

**Linux / macOS**

```bash
./othello
```

**Windows**

```bash
.\Debug\othello.exe
```

## 🎲 How to Play

- Black always moves first.
- Place a disk to capture your opponent's disks.
- Captured disks are flipped to your color.
- The player with the most disks at the end wins.

## 🛠 Technologies

- **Language:** C++17
- **Build System:** CMake
- **Libraries:** Standard Template Library (STL)
